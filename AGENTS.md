## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Posts

`src/content/posts` is gitignored and expected to be a symlink or clone of the private posts repository, so a fresh clone has no content until it is linked:

```
ln -s ~/Documents/posts src/content/posts
```

CI replaces the directory with a checkout of the same repository. A missing directory is not an error; the site just builds without posts.
